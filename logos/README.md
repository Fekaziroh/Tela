# Logos

Tela! ships no logos (they are trademarks of their brands). Without logo files, the screen shows the
detected brand names as text.

To use logos, add PNG files in **Appearance › Logos › Add…**. They are kept in `%APPDATA%\Tela\logos`
and survive updates. Name files after the brand (e.g. `AMD.png`, `MSI.png`) so the automatic mode can
match them to your hardware.
